# MinerPartner Torch

Auto torch placement mod for GT New Horizons.

## Features

- Auto torch placement when surroundings get dark
- Y key toggle with status messages
- Smart light detection (same as NEI F7)
- Configurable light threshold, scan radius, cooldown

## Usage

1. Place torches in hotbar (slots 0-8)
2. Press Y to enable
3. Walk into dark areas for auto placement
4. Press Y to disable

## Requirements

- Minecraft 1.7.10, Forge 10.13.4.1614+
- GT New Horizons 2.9.0+
